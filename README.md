# Promo Effectiveness & Customer Retention Analysis (Olist E-Commerce Dataset)
A/B testing and cohort retention analysis on Brazilian e-commerce data.

## Key Finding
Voucher-based orders show significantly lower average order value (₹65.70 vs ₹163.32, p<0.001) 
compared to credit card orders. Cohort analysis shows retention drops below 1% after month 1 
for nearly all cohorts, indicating Olist customers are largely one-time buyers.

## Tools
Python, Pandas, SciPy, Seaborn, Matplotlib

## Dataset
Brazilian E-Commerce Public Dataset by Olist (Kaggle)
